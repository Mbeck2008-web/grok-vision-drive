This folder's tesla_model3_ego.glb is that model, prepared for the GVD C++
visualizer (gvd_viz) as the ego car.

The public copy used to prepare this file came from GitHub
wass08/r3f-3d-slideshow @ 4672444 (commit 4672444b40fcdf9830985b4d7fad90bb01c7993d),
path public/models/model3_scene.glb
(https://github.com/wass08/r3f-3d-slideshow). That repo's README credits
the same David_Holiday Sketchfab model as CC BY 4.0.
  SHA-256 (model3_scene.glb): 98ecdd9299e871e72852fad4327754689644d45620e4f2ba8bc014ee708f5502
  Size: 295,892 bytes (Draco-compressed GLB).

model3_scene.glb is a slideshow scene, not a standalone car (it also has
non-car props this project does not redistribute). A car-only extract
(model3_car_only.glb: body, glass, wheels, calipers, a small interior) was
the direct source for tesla_model3_ego.glb. That extract has 26,942 triangles;
Sketchfab lists 27,012 for the standalone model, a 70-triangle gap that was
not further reconciled.

Changes made (CC BY 4.0 requires that adaptations be indicated):
  - The embossed Tesla "T" badge on the hood was removed (307 triangles).
  - The rear Tesla "T" badge on the trunk lid at the base of the glass
    (~7 cm, 181 triangles) was also removed. The T-shaped cutout that
    left in the rear glass was filled (84 triangles, glass colour) and
    the hole-rim vertices were flattened onto the surrounding glass
    band (max 6 mm) so the rear is closed and clean.
  - Axes were converted to the visualizer ego frame (X right, Y forward,
    Z up), length-centered, with the wheels on the ground. In this file
    the bounding box is 4.354 m long (including mirrors).
  - At load, python/viz/rv_ego_model.fit_to_ego applies a non-uniform
    scale of x 0.946, y 1.084, z 1.060 (width, length, height) so the
    fitted bounding box is 1.85 m wide x 4.72 m long x 1.44 m tall
    (the x squash is wheel thickness only).
  - Vertex colours were assigned (body, glass, wheels, lamps) for the
    flat-shaded mesh shader; the original placeholder textures were dropped.
  - No decimation. Triangle count after both badge removals and the
    rear-glass fill: 26,538 (under 30,000).
