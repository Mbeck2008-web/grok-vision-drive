# Why these versions (sources in docs/ort_bench.md "Pins"):
# - CUDA 13 dropped Pascal (sm_61). onnxruntime-gpu on PyPI is built with CUDA 13 from 1.27.0,
#   so 1.26.x is the last PyPI onnxruntime-gpu built with CUDA 12.8.
# - cuDNN dropped pre-Turing after 9.10.x; onnxruntime-gpu's [cudnn] extra only asks for
#   nvidia-cudnn-cu12~=9.0 (would pull a Pascal-less 9.1x/9.2x), so cuDNN is pinned to
#   9.10.2.21, the same cuDNN torch 2.14.1+cu126 depends on.
# - Driver: CUDA 12.8 runtime needs an R570+ driver (minor-version compat from R525 may
#   work for most kernels; UNVERIFIED on IQU45).
